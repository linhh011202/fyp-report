\subsection{Frontend Design}

The frontend is built with Vue.js 3, which provides a modern reactive framework with excellent TypeScript support. Vue Router handles navigation between different pages, while Axios manages all communication with the backend. Vuetify components enable rapid development while maintaining a consistent, professional Material Design appearance across the application.

\subsection{Backend Architecture}

The backend is implemented with NestJS, a progressive Node.js framework that enforces modular, scalable architecture patterns. TypeScript ensures type safety throughout the codebase, reducing runtime errors and improving code maintainability. Authentication is managed through Passport middleware combined with JWT tokens, allowing stateless, scalable session handling without server-side session storage.

\subsection{Data Storage and Caching}

MongoDB serves as the primary data store, offering flexible document-based storage that adapts as the application evolves. To optimize performance, frequently accessed data—such as service plans and pricing information—is cached in Redis. This caching strategy reduces database load and API latency by checking the fast in-memory cache first, falling back to the database only when the cache is empty. When a cache miss occurs, the retrieved data is stored for future requests, creating a simple yet effective read-through cache pattern.

\subsection{External Integrations}

The system integrates with three key external services. Google OAuth and Apple Sign-In provide secure, passwordless authentication, reducing the application's authentication overhead while leveraging trusted identity providers. Stripe handles all payment processing, including subscription creation, billing cycles, and transaction management, ensuring compliance with PCI standards and industry best practices.
