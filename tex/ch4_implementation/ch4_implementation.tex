\chapter{Implementation}
\label{chap:implementation}

This chapter describes the implementation of the Gateway Dashboard system, organised into two main parts. The first part covers the backend services, including the authentication system with Single Sign-On support and the payment and subscription management infrastructure. The second part covers the frontend dashboard application built with Vue.js.

\section{Backend Implementation}
